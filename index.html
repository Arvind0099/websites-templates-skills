Each style is a single HTML file with no build step, packaged as a reusable skill. Open a live demo, scroll and click around, then install the one you like.

Install the skills

Copies every skill into your skills folder so it works in all your projects.

🪟 Windows (PowerShell)
git clone https://github.com/Arvind0099/websites-templates-skills.git
cd websites-templates-skills
powershell -ExecutionPolicy Bypass -File .\install.ps1
🍎 macOS / 🐧 Linux
git clone https://github.com/Arvind0099/websites-templates-skills.git
cd websites-templates-skills
sh install.sh
